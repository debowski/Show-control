# 05: Czyszczenie całej playlisty

**What to build:** Jedna akcja usuwa wszystkie pozycje playlisty, zamiast
klikania pojedynczo. Jeśli coś gra, playback się zatrzymuje. Po wyczyszczeniu
operator widzi pustą playlistę gotową na nowy scenariusz.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Dostępna akcja „Wyczyść playlistę" (przycisk lub skrót z tabeli skrótów)
- [ ] Akcja usuwa wszystkie pozycje, także ukryte przez filtr
- [ ] Jeśli coś grało, playback zostaje zatrzymany
- [ ] Pusta playlista nie zostawia wskaźnika odtwarzania ani czasu
